Fiktiver Kunde: PLAYDATE, Games & Community (Briefing B08). Team: Stephanie & Julia.

## Dateien
- `index.html` – Startseite
- `spieleabend.html` – Angebotsseite mit Reservation (CTA)
- `erster-besuch.html` – Content-Seite (FAQ, Ratgeber, Video)
- `style.css` – Design
- `media/` – hier kommt euer Video hinein (`regeltest.mp4`)

## Auf GitHub Pages veröffentlichen
1. Auf github.com einloggen → oben rechts **+** → **New repository**.
2. Name z. B. `playdate`, auf **Public** stellen → **Create repository**.
3. Auf **uploading an existing file** klicken und alle Dateien aus diesem Ordner hineinziehen (inkl. Ordner `media`). Unten **Commit changes**.
4. Im Repository: **Settings** → **Pages** → bei *Branch* `main` und `/ (root)` wählen → **Save**.
5. Nach 1–2 Minuten erscheint oben der Link, z. B. `https://BENUTZERNAME.github.io/playdate/`. Diesen Link auf Moodle abgeben.

## Video einbauen (nach dem Dreh)
1. Video als MP4 exportieren, Name `regeltest.mp4`, möglichst unter 50 MB.
2. In `media/` auf GitHub hochladen.
3. In `erster-besuch.html` das `<div class="video-placeholder">…</div>` löschen und bei der Zeile `<video …>` die Kommentarzeichen `<!--` und `-->` entfernen.
4. Die gelb markierten Stellen **[NACH DEM DREH AUSFÜLLEN]** und **[Datum]** ersetzen (danach kann der `.todo`-Stil bleiben, er wird nicht mehr verwendet).

Alternative: Video auf YouTube (nicht gelistet) hochladen und den Link einbauen.
